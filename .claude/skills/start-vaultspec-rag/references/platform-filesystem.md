## Limits and reconciliations

Findings describe the inspected snapshot. External dependency internals and operational outcomes were not verified. Test assertions and recorded benchmark results do not establish a current passing run.

- OS/library effects, permissions, native handles and complete callers remain unverified.
- These shared primitives do not independently grant mutation authority; authority stays with callers.
- s1-0033 broad watcher_runtime awatch docstring is not its implementation role. s1-0032 identifies the actual native intake loop; retry/runtime are coordination layers. watcher_intake.py owns native intake/awatch; watcher runtime/retry coordinate it. This is a docstring scope discrepancy, not an uninspected loop.
- s1-0111 describes a computed monitor spawn-scan target as src/monitor/server/\*.ts; s1-0104/0105 name src/vaultspec_rag/monitor/server/local-service.ts. This is uncertain report path wording, not proof of a faulty scan. The included source inventory places the monitor bridge at src/monitor/server/local-service.ts; the src/vaultspec_rag/monitor/ locator in test-only report prose is incorrect. The derived src/monitor/server target matches the source layout, while runtime scan effectiveness remains unverified.
- Coverage qualification, not an established implementation defect: test_daemon_survives_shell_exit.py explicitly excludes full Windows shell-exit/Job-Object survival despite its broad filename. Retain the test's explicit exclusion of full Windows shell-exit/Job-Object survival. Shared process primitives are inspected, but this broader runtime scenario remains unverified.
