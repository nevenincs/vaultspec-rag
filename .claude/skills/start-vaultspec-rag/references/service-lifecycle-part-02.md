## Capability summary

- [src/vaultspec_rag/cli/\_service_jobs_presentation.py](../../../../src/vaultspec_rag/cli/_service_jobs_presentation.py) owns human-readable job list and detail views: phase/operation/project labels, progress and ETA, health/degradation evidence, resource/runtime/resilience/controller details, error summaries, retry lineage, counts, filters, and empty results. `render_jobs_result` dispatches to empty, detail, or feed views. (135-223, 259-274, 468-533, 639-721, 854-934, 936-1131, 1134-1168)
- [src/vaultspec_rag/cli/\_service_jobs_query.py](../../../../src/vaultspec_rag/cli/_service_jobs_query.py) resolves CLI-facing state/trigger/index filters, constructs a `JobsQuery`, translates it to service arguments, reads jobs through the admin transport, and applies active/waiting filtering client-side. It also provides waiting/admission predicates and empty-result text. (15-56, 82-215, 226-300)
- [src/vaultspec_rag/cli/\_service_jobs_watch.py](../../../../src/vaultspec_rag/cli/_service_jobs_watch.py) adapts a resolved fetch request to the jobs TUI, applying the same client-side state filter on every poll. It rejects incompatible JSON/watch arguments. (23-67)
- [src/vaultspec_rag/cli/\_service_lifecycle.py](../../../../src/vaultspec_rag/cli/_service_lifecycle.py) centralizes lifecycle text/JSON success and failure rendering and the discovery-file unlink predicate; it also implements `server warmup`, delegating environment judgment and model provisioning, then reporting results. (34-142, 150-245)
- [src/vaultspec_rag/cli/\_service_logs.py](../../../../src/vaultspec_rag/cli/_service_logs.py) registers `server logs` options through a custom Typer command, prefers the live admin route when a port is available, falls back to local managed-log querying when the live call yields no result, validates live payloads, and emits JSON or grouped text. (54-123, 149-205)
- [src/vaultspec_rag/cli/\_service_preflight.py](../../../../src/vaultspec_rag/cli/_service_preflight.py) implements read-only `server preflight`: validates discovery freshness and identity, reads health/capacity and authenticated service state, strictly validates quiesce/capacity shapes, reports failures closed, and always states that a separate borrower lease is required. (32-190, 193-272, 275-357, 359-495)
- [src/vaultspec_rag/cli/\_service_projects.py](../../../../src/vaultspec_rag/cli/_service_projects.py) implements `server projects list` and `unload`, formatting loaded-project activity and capacity, and reporting service-unavailable, busy, not-found, or successful unload outcomes in human or JSON form. (83-185, 188-302)
- [src/vaultspec_rag/cli/\_service_qdrant.py](../../../../src/vaultspec_rag/cli/_service_qdrant.py) implements `server qdrant install`, `status`, `clean`, and `quarantine`. Install delegates provisioning and reports source/checksum details; status combines binary verification, endpoint readiness, service process state, and provisioned versions; clean previews or removes managed installs; quarantine lists or moves a named collection aside after confirmation. (93-197, 200-288, 394-421, 424-519, 522-637)
- [src/vaultspec_rag/cli/\_service_quiesce.py](../../../../src/vaultspec_rag/cli/_service_quiesce.py) implements `server pause` and `resume` as adapters over service-owned admin transitions, accepting success only when the returned canonical state matches the requested direction. (32-108, 111-126)
- [src/vaultspec_rag/cli/\_service_reconcile.py](../../../../src/vaultspec_rag/cli/_service_reconcile.py) implements bounded `server reconcile`, polling discovery/liveness/health convergence and rendering final evidence in JSON or human form. (43-114, 117-130)

## Interfaces and data flow

- Jobs: `JobsQuery` carries port, limit, and optional filters. `_jobs_args` maps it to the `get_jobs` admin call; `apply_client_state_filter` narrows returned rows for active/waiting state. `render_jobs_result` then sends the result to feed, empty, or single-job detail rendering. Watch wraps the same fetch and filter in `JobsWatchRequest` before calling the TUI. (175-215, 267-300 in [src/vaultspec_rag/cli/\_service_jobs_query.py](../../../../src/vaultspec_rag/cli/_service_jobs_query.py); 23-67 in [src/vaultspec_rag/cli/\_service_jobs_watch.py](../../../../src/vaultspec_rag/cli/_service_jobs_watch.py); 1134-1168 in [src/vaultspec_rag/cli/\_service_jobs_presentation.py](../../../../src/vaultspec_rag/cli/_service_jobs_presentation.py))
- Logs: parsed command options become `_ServiceLogsOptions`; `_run_service_logs` resolves a port, requests `get_logs`, and either validates the live response or calls the local managed-log query. Both paths produce a payload/group set for JSON or plain grouped output. (54-123, 158-205 in [src/vaultspec_rag/cli/\_service_logs.py](../../../../src/vaultspec_rag/cli/_service_logs.py))
- Lifecycle and project commands expose Typer command functions with port/JSON options as applicable. Warmup delegates to model provisioning; projects list reads `list_projects`, while unload calls `evict_project`. Shared lifecycle helpers return exit 1 for lifecycle failure and provide a common success envelope/text path. (57-122, 164-245 in [src/vaultspec_rag/cli/\_service_lifecycle.py](../../../../src/vaultspec_rag/cli/_service_lifecycle.py); 137-185, 251-302 in [src/vaultspec_rag/cli/\_service_projects.py](../../../../src/vaultspec_rag/cli/_service_projects.py))
- Qdrant commands delegate installation, binary resolution/verification, endpoint probing, install listing, cleaning, and collection quarantine to imported provisioning/runtime helpers. Clean and quarantine expose preview/confirmation gates. (106-197, 212-288, 432-519, 547-637 in [src/vaultspec_rag/cli/\_service_qdrant.py](../../../../src/vaultspec_rag/cli/_service_qdrant.py))
- Preflight reads machine discovery, health, device-load evidence, then authenticated service-state using the discovery token. It emits a successful observation only for a structurally valid, acknowledged safe-quiesce snapshot; output still marks `authorized: false` and `lease_required: true`. (225-247, 275-309, 359-495 in [src/vaultspec_rag/cli/\_service_preflight.py](../../../../src/vaultspec_rag/cli/_service_preflight.py))
- Pause/resume send `pause_service` or `resume_service` admin requests; reconcile repeatedly invokes supplied discovery, liveness, and health probes through `reconcile_discovery`. Both surface structured and human outcomes. (32-96 in [src/vaultspec_rag/cli/\_service_quiesce.py](../../../../src/vaultspec_rag/cli/_service_quiesce.py); 80-114 in [src/vaultspec_rag/cli/\_service_reconcile.py](../../../../src/vaultspec_rag/cli/_service_reconcile.py))
