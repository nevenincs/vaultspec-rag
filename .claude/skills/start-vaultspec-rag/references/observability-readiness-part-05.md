## Capability summary

This slice maps the jobs test surface. It specifies registry lifecycle and serialization, progress telemetry and estimation, liveness/degradation evidence, CLI presentation, route projections, device admission readings, quiesce state, and rebuild reconciliation. These are test contracts only; production implementation was not inspected.

- [src/vaultspec_rag/tests/test_jobs_degradation.py](../../../../src/vaultspec_rag/tests/test_jobs_degradation.py) covers forward-pass telemetry seams for dense and sparse encoding; encode evidence shape; healthy/degraded/stalled verdicts; phase-aware evidence; CPU/GPU/backend snapshots and cache behavior; `/jobs` GPU exposure; progress-rate collapse against a run baseline; live local-backend probing; and equality between legacy terminal-phase keys and the terminal set. Its tests invoke imported reporter, progress, evidence, and route helpers; their implementations and the streaming modules are uninspected.
- [src/vaultspec_rag/tests/test_jobs_degradation_display.py](../../../../src/vaultspec_rag/tests/test_jobs_degradation_display.py) specifies CLI rendering of service degradation verdicts and evidence, fallback behavior when an older daemon omits the verdict, phase-aware encode/CPU lines, encode batch and sub-slice counts, throughput-collapse summaries, and the code pipeline progress label.
- [src/vaultspec_rag/tests/test_jobs_device_load.py](../../../../src/vaultspec_rag/tests/test_jobs_device_load.py) specifies the device-load snapshot's cache freshness, defensive-copy behavior, cached `None` behavior, and presence/shape of the `/jobs` response member.
- [src/vaultspec_rag/tests/test_jobs_eta_display.py](../../../../src/vaultspec_rag/tests/test_jobs_eta_display.py) specifies feed/detail rendering for present estimates, explicit null estimates, and absent fields; suppression for stalled, queued, and finished jobs; and edge formatting for rounded, negative, and zero estimates.
- [src/vaultspec_rag/tests/test_jobs_lifecycle.py](../../../../src/vaultspec_rag/tests/test_jobs_lifecycle.py) specifies job start/finish and snapshot ordering; preprocess fields and defensive copies; lifecycle event logs and error-kind classification; legacy and canonical liveness/control projections, filters, ordering, and summaries; `index_job_status`; CLI JSON signposting/help metadata; interrupted-job restoration and attribution; and suite machine-directory isolation.
- [src/vaultspec_rag/tests/test_jobs_progress_emission.py](../../../../src/vaultspec_rag/tests/test_jobs_progress_emission.py) specifies separate throttled progress-log and durable-snapshot writes, immediate writes on step transition, live in-memory advancement during coalescing, and omission of throttle state from snapshots.
- [src/vaultspec_rag/tests/test_jobs_progress_rate.py](../../../../src/vaultspec_rag/tests/test_jobs_progress_rate.py) specifies sample-window rate guards, resets on step changes or count rewind, transient-state omission from snapshots, ETA projection, realistic high-cadence coalescing, slowdown tracking, and rate-without-ETA when total work is absent.
- [src/vaultspec_rag/tests/test_jobs_quiesce_projection.py](../../../../src/vaultspec_rag/tests/test_jobs_quiesce_projection.py) specifies that authenticated `/jobs` observations carry the controller-derived quiesce envelope through running, quiesced, and resumed states.
- [src/vaultspec_rag/tests/test_jobs_rebuild_reconciliation.py](../../../../src/vaultspec_rag/tests/test_jobs_rebuild_reconciliation.py) specifies that rebuild completion invokes watcher reconciliation on a worker thread, away from the event-loop thread.
