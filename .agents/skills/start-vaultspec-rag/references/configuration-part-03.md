## Capability summary

- [src/vaultspec_rag/config/\_credentials.py](../../../../src/vaultspec_rag/config/_credentials.py) — exposes the daemon credential list, resolves a registered workspace credential through the framework accessor, and builds (ConfigVariable, key) assignments for a child process. The code permits the workspace-root .env behavior only through the delegated framework call; this file itself does not open a file (22-25, 34-39, 42-58, 61-93).
- [src/vaultspec_rag/config/\_paths.py](../../../../src/vaultspec_rag/config/_paths.py) — owns the managed status-directory path lookup, local-only marker path, persistence/read functions for that marker, and the shared service.json filename constant (14-30, 33-48, 51-73, 76-101).
- [src/vaultspec_rag/config/\_registry.py](../../../../src/vaultspec_rag/config/_registry.py) — translates each EnvVar into a framework ConfigVariable, classifying scope, secret status, .env eligibility, fail-safe status, fallback, and description; registers the resulting entries under package name vaultspec-rag and exposes entry(var) (52-54, 62-138, 140-155, 324-396).
- [src/vaultspec_rag/config/\_schema.py](../../../../src/vaultspec_rag/config/_schema.py) — defines reusable bounds and normalization for numbers, enumerated choices, HTTPS URLs, host lists, and hexadecimal identifiers; maps settings keys to environment variables and maps constrained keys to their bounds; provides rejection construction and checked_setting validation/narrowing (17-91, 94-102, 105-243, 246-336, 339-491, 494-635).

## Interfaces and data flow

- Registry flow: EnvVar members feed \_ENTRIES; \_description uses a written description or the setting key and optional bound shape; register_registry(PACKAGE, \_ENTRIES.values()) publishes the entries, and entry(var) returns one ([src/vaultspec_rag/config/\_registry.py](../../../../src/vaultspec_rag/config/_registry.py) 140-155, 324-396). The entry declarations use string values with attr_name=None and default=None; they describe names and classification, while setting validation is in [src/vaultspec_rag/config/\_schema.py](../../../../src/vaultspec_rag/config/_schema.py) ([src/vaultspec_rag/config/\_registry.py](../../../../src/vaultspec_rag/config/_registry.py) 10-17, 367-384).
- Settings flow: ENV_OVERRIDE_MAP maps setting keys to EnvVar members, with comments identifying special cases excluded from the plain map (log_level and transformed preprocess_mode) ([src/vaultspec_rag/config/\_schema.py](../../../../src/vaultspec_rag/config/_schema.py) 339-491). SETTING_BOUNDS maps constrained keys to bound objects ([src/vaultspec_rag/config/\_schema.py](../../../../src/vaultspec_rag/config/_schema.py) 494-635). checked_setting(name, value, source) returns an unconstrained value unchanged, otherwise rejects a value outside the bound or returns its narrowed form ([src/vaultspec_rag/config/\_schema.py](../../../../src/vaultspec_rag/config/_schema.py) 316-336). Its external invocation sites are not in the assigned ranges.
- Credential flow: workspace_credential(var, root, interpreter_prefix=...) passes entry(var) and its arguments to resolve_credential; credential_assignments(root, ...) returns empty for no root, otherwise resolves each member of DAEMON_CREDENTIALS and returns the registered variable/value pairs for credentials found ([src/vaultspec_rag/config/\_credentials.py](../../../../src/vaultspec_rag/config/_credentials.py) 34-39, 42-58, 61-93). Framework resolution details are outside the inspected source.
- Marker flow: the path is Path(os.environ[STATUS_DIR] or STATUS_DIR_DEFAULT).expanduser() / local-only.json ([src/vaultspec_rag/config/\_paths.py](../../../../src/vaultspec_rag/config/_paths.py) 33-48). Persistence sends {"local_only": bool(value)} to write_json_atomically; reading treats missing, unreadable, malformed, or non-boolean values as absent and returns a boolean only for a JSON boolean ([src/vaultspec_rag/config/\_paths.py](../../../../src/vaultspec_rag/config/_paths.py) 51-73, 76-101). Atomic-write internals are uninspected.
- SERVICE_STATUS_FILENAME is the literal service.json ([src/vaultspec_rag/config/\_paths.py](../../../../src/vaultspec_rag/config/_paths.py) 24-30). Its comment names client, daemon, machine-pointer, and indexer roles as readers; actual call sites are not included ([src/vaultspec_rag/config/\_paths.py](../../../../src/vaultspec_rag/config/_paths.py) 24-29).
