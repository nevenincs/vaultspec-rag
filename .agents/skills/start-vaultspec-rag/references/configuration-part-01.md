## Capability summary

- [conftest.py](../../../../conftest.py) is the repository-wide pytest harness. It suppresses os.fsync/os.fdatasync during tests, with an autouse fixture restoring real syncing for durable-marked tests; it also disables SQLite syncing only for files named storage.sqlite. It reports suppression totals, captures a pre-provisioned verified Qdrant binary for lifecycle fixtures, brokers selected GPU-tier sessions through a child pytest process and service borrow, enforces tier and environment-isolation hooks, and optionally configures a JUnit report path.
- [dependency-audit-allowlist.toml](../../../../dependency-audit-allowlist.toml) records accepted OSV advisory suppressions with reasons and expiry dates. Its only present entry is GHSA-vfj7-8cjw-p6xm, expiring 2026-11-04.
- [dependency-audit-binaries.toml](../../../../dependency-audit-binaries.toml) declares a shipped binary not represented by a package lockfile: crates.io pyapp 0.29.0.
- [devserver-ruff.toml](../../../../devserver-ruff.toml) supplies a separate Ruff profile for the shared lifecycle script: 120-character lines, Python 3.12 target, and E/F/I/B/UP/SIM rule families.
- eslint.config.js configures flat ESLint rules for JavaScript and TypeScript/TSX, with Node globals for JS, browser and Node globals for TS/TSX, recommended JS and TypeScript rules, and React Hooks rules. It excludes generated/dependency directories and release artifacts.
- justfile is the user-facing development command catalog. It groups recipes by consequence: setup, day-to-day dev, gates, fixes, advisory audits, health measurements, tests, builds, documentation, release, and composed CI. Bodies dispatch to dev/ modules, npm, or direct Python entry points. The file says [dev/toolchain.py](../../../../dev/toolchain.py) is the declarative source of truth behind the Python toolchain recipes and help.
- [lychee.toml](../../../../lychee.toml) configures link checking: accepted HTTP statuses, excluded URL patterns and paths, progress suppression, and verbosity.
- [package.json](../../../../package.json) declares a private ESM monitor frontend, Node/npm version ranges, monitor devserver ports/host/allowed hosts, npm scripts, and pinned frontend/runtime and tooling dependencies.
- [pyproject.toml](../../../../pyproject.toml) defines the Python package, runtime and optional dependencies, development dependency groups, package build inclusion, pytest conventions, and Python lint/type/security/dependency-audit settings.
- [release-please-config.json](../../../../release-please-config.json) configures a draft Python release for the root package, component tags, version-bump behavior, changelog sections, and the extra file [docs/installation.md](../../../../docs/installation.md).
- [taplo.toml](../../../../taplo.toml) configures TOML formatting.
- [tsconfig.json](../../../../tsconfig.json) configures strict, no-emit TypeScript checking for the Vite config and monitor TS/TSX sources.
- [vite.config.ts](../../../../vite.config.ts) sets the monitor source root, relative asset base, React and local-service plugins, and strict dev/preview hosts and ports derived from [package.json](../../../../package.json).

## Interfaces and data flow

- Pytest receives its normal invocation arguments, options, collected items, markers, and process environment. The root harness reads options and markers to decide whether collection or execution is requested, whether selected GPU tiers require a borrow, and whether CI reporting is opted in. For selected non-MPS GPU work, a collect-only child reports one of two private status codes; the parent then runs the suite in another child while holding the service borrow. The child runs its own pytest configuration and directory guard. Xdist worker counters return through workeroutput; terminal output announces both the test-session substitution and aggregated counts. ([conftest.py:32-45, 241-279, 390-560, 593-696, 697-870](../../../../conftest.py#L32))
- Pytest environment containment saves and later restores selected environment variables, redirects status, Qdrant storage, uv environment, and pytest temporary paths beneath a per-session root, and retains failure artifacts. The optional CI report is enabled by VAULTSPEC_CI_REPORTS, can be named by VAULTSPEC_CI_REPORT_NAME, and yields to an explicit --junitxml argument. ([conftest.py:46-60, 618-695, 710-775, 890-924](../../../../conftest.py#L46))
- The just command is the command-line entry point for repository tasks. Python-tool recipes mostly call uv run --no-sync python -m dev with task arguments; setup and release recipes use no-project interpreters, while frontend recipes call npm scripts. Individual recipes expose inputs such as release tag, Rust target, output directory, frontend revision/digest, browser, and checksum paths. (justfile:50-124, 151-210, 216-320, 324-468, 474-509, 521-564)
- npm scripts call Vite, ESLint, Prettier, and TypeScript; Vite resolves the monitor root, imports the package manifest for host/port configuration, and registers the local-service plugin. ([package.json:10-48](../../../../package.json#L10); [vite.config.ts:1-25](../../../../vite.config.ts#L1); [tsconfig.json:1-22](../../../../tsconfig.json#L1))
- Project outputs/configured effects include the wheel and sdist, optional JUnit XML and pytest temporary artifacts, frontend build output under src/monitor/dist, and release artifacts through the listed recipes. The cited config declares these paths; the build implementations were not inspected. (justfile:116-124, 474-489, 521-564; [pyproject.toml:171-195](../../../../pyproject.toml#L171); [conftest.py:873-924](../../../../conftest.py#L873))
