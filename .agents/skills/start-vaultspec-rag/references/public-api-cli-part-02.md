- [src/vaultspec_rag/cli/__init__.py](../../../../src/vaultspec_rag/cli/__init__.py): Forms the `vaultspec_rag.cli` package. It imports command modules for registration side effects, then exposes the Typer root app, shared Rich console, and `TerminationResult`. The module's documentation says command functions are reached through CLI dispatch rather than package-level re-exports. The imported modules beyond this slice are named but not inspected. ([src/vaultspec_rag/cli/__init__.py:9-35,40-66,68-92](../../../../src/vaultspec_rag/cli/__init__.py#L9))
- [src/vaultspec_rag/cli/\_app.py](../../../../src/vaultspec_rag/cli/_app.py): Owns the root Typer app, server/preprocess sub-apps, shared CLI option declarations, version callback, root callback, and per-invocation state. Its custom root group disables Windows shell-style argument expansion and saves invocation tokens and parsed root options in Click context metadata. Root setup validates environment settings, publishes the model-hub endpoint, configures logging, resolves the named project root, seeds process configuration, and either places a short-circuit target in `ctx.obj` or resolves a workspace into `CLIState`. ([src/vaultspec_rag/cli/\_app.py:67-138,152-279,281-322,325-397,496-504,505-719](../../../../src/vaultspec_rag/cli/_app.py#L67))
- [src/vaultspec_rag/cli/\_cli_format.py](../../../../src/vaultspec_rag/cli/_cli_format.py): Provides shared stateless presentation helpers for counts, elapsed durations, numeric validation, compact durations, sizes, project names, and path labels. Missing or non-finite values are rendered as absent; negative numeric values are clamped by duration formatters. Size conversion delegates to `_units`. ([src/vaultspec_rag/cli/\_cli_format.py:52-87,89-124,127-187,190-212](../../../../src/vaultspec_rag/cli/_cli_format.py#L52))
- [src/vaultspec_rag/cli/\_core.py](../../../../src/vaultspec_rag/cli/_core.py): Creates the package-wide logger and one Rich console. On Windows it attempts to set UTF-8 on wrapped stdout/stderr. Interactivity is decided with the real stdout's `isatty()`; the console builder disables highlighting and enables forced terminal/interactivity only for an interactive stream. ([src/vaultspec_rag/cli/\_core.py:28-40,43-59,62-110](../../../../src/vaultspec_rag/cli/_core.py#L28))
- [src/vaultspec_rag/cli/\_gpu_errors.py](../../../../src/vaultspec_rag/cli/_gpu_errors.py): Centralizes local-GPU ownership refusals and operator-facing torch/GPU/MPS remediation. It can warn from a child-interpreter capability probe or handle a compute exception using the current process's loaded torch state/probe. JSON refusal output is delegated to the renderer; human remediation uses plain output and exits with status 1. ([src/vaultspec_rag/cli/\_gpu_errors.py:28-92,94-137,139-217,219-283](../../../../src/vaultspec_rag/cli/_gpu_errors.py#L28))
- [src/vaultspec_rag/cli/\_gpu_lease.py](../../../../src/vaultspec_rag/cli/_gpu_lease.py): Provides fail-closed coordination for explicit local GPU borrowing. It acquires a borrower lease, discovers and version-checks the service, sends authenticated pause/resume admin requests, requires an exact quiesce snapshot before work, and releases the lease only after no pause was attempted or resume is acknowledged. On failed/unverifiable resume, it retains the lease for process-exit recovery. ([src/vaultspec_rag/cli/\_gpu_lease.py:45-112,114-184,239-355](../../../../src/vaultspec_rag/cli/_gpu_lease.py#L45))
- [src/vaultspec_rag/cli/\_index.py](../../../../src/vaultspec_rag/cli/_index.py): Registers `index` and `clean`. Index supports source selection, rebuilding, audit verification, dry-run discovery, service delegation, and explicit borrower-coordinated local indexing. It renders human summaries or structured JSON and maps locking, disk, service, and GPU failures to command errors. Clean requires an explicit source argument, confirms destructive work unless `--yes` is supplied, requires `--yes` in JSON mode, invokes the clean API, and renders cleared-source results. ([src/vaultspec_rag/cli/\_index.py:73-107,122-206,209-271,274-463,466-592,631-778,780-978,979-1195,1198-1308](../../../../src/vaultspec_rag/cli/_index.py#L73))

## Interfaces and data flow

- Package import builds the CLI surface by importing command modules for decorator registration and exports `app`, `console`, and `TerminationResult`. [src/vaultspec_rag/cli/\_app.py](../../../../src/vaultspec_rag/cli/_app.py) declares the main app plus `server` groups (`job`, `projects`, `updates`, `qdrant`, `storage`) and `preprocess`; callbacks show group help when no nested command runs. The package import-order contract and registration behavior are described in comments/docstrings, while the individual out-of-slice command modules were not inspected. ([src/vaultspec_rag/cli/__init__.py:9-27,40-66](../../../../src/vaultspec_rag/cli/__init__.py#L9); [src/vaultspec_rag/cli/\_app.py:325-393,400-469](../../../../src/vaultspec_rag/cli/_app.py#L325))
- Root CLI options are captured by `_LiteralArgvGroup`. It preserves the raw invocation tokens on the root context, extracts global options before the root callback, then restores Click's params after invoking the callback. `main` passes those options into root configuration. The callback refuses unusable settings before logging, publishes the configured hub endpoint, configures logging, resolves the selected root, seeds configuration, and sets `ctx.obj` for downstream commands. ([src/vaultspec_rag/cli/\_app.py:173-322,496-504,505-547,550-609,611-719](../../../../src/vaultspec_rag/cli/_app.py#L173))
- `index` receives `CLIState.target` plus Typer options. Source parsing accepts aliases according to `parse_source_type(..., allow_aliases=True)`; malformed input exits 2, with a JSON error when requested. Rebuild requires an explicitly supplied type. Full audit also requires an explicit type and rejects publication/local-run options; it resolves a service and calls the audit transport with `AUDIT_VERIFICATION` authority. ([src/vaultspec_rag/cli/\_index.py:122-149,466-498,631-684,730-778,780-908](../../../../src/vaultspec_rag/cli/_index.py#L122))
- Dry-run validates the source and non-negative sample bound, optionally sets the preprocess environment switch, then scans code and/or documents without opening index storage. Its JSON projection contains total/counts, file lists, truncation, document fingerprints/policy fields, and code admission evidence; human mode prints a bounded listing and admission summary. ([src/vaultspec_rag/cli/\_index.py:274-349,352-402,404-463](../../../../src/vaultspec_rag/cli/_index.py#L274))
- Publication indexing selects authority from `--rebuild`. With `--borrow-gpu`, the local indexing closure runs inside `run_with_borrowed_gpu`; otherwise it discovers/uses a service and delegates over HTTP when available. A reachable but incompatible service is refused. If no service can handle the request, local execution is refused unless explicit GPU borrowing was requested. The in-process path invokes the selected API by source, captures per-domain rows, and emits a JSON result or human summary. ([src/vaultspec_rag/cli/\_index.py:269-271,500-568,579-593,909-978,979-1183,1185-1195](../../../../src/vaultspec_rag/cli/_index.py#L269))
- Clean parses the required source argument, prompts unless confirmed, refuses JSON without `--yes`, calls `vaultspec_rag.clean` with the registry, then emits `clean_type`, canonical `source`, and `cleared` in JSON or a human summary. ([src/vaultspec_rag/cli/\_index.py:1198-1308](../../../../src/vaultspec_rag/cli/_index.py#L1198))
- Borrower coordination data flow is: local lease acquisition → service discovery/version compatibility → authenticated pause carrying the lease capability → exact typed snapshot and safe-state checks → work → authenticated resume → lease release. HTTP admin outcomes that do not match the known quiesce envelope are treated as contract mismatch. ([src/vaultspec_rag/cli/\_gpu_lease.py:53-112,114-184,239-355](../../../../src/vaultspec_rag/cli/_gpu_lease.py#L53))
- GPU error handling distinguishes an ownership refusal before environment diagnosis, then classifies torch/accelerator capability and chooses a human remediation message. The warning helper accepts an already-probed capability or probes the active interpreter. ([src/vaultspec_rag/cli/\_gpu_errors.py:61-74,139-217,219-283](../../../../src/vaultspec_rag/cli/_gpu_errors.py#L61))
