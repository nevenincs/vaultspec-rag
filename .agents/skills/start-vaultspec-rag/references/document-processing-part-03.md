## Capability summary

- [src/vaultspec_rag/tests/integration/test_cli_ux_testimonial.py](../../../../src/vaultspec_rag/tests/integration/test_cli_ux_testimonial.py): Scripted operator journeys cover CLI help and plain status, live code indexing/search, and flattened server status/logs/jobs/updates/projects commands, both with and without a daemon. The live search builds a synthetic workspace and uses an isolated service state.
- [src/vaultspec_rag/tests/integration/test_codebase_integration.py](../../../../src/vaultspec_rag/tests/integration/test_codebase_integration.py): Real-store code indexing expectations cover full and incremental runs, idempotence, new/modified/deleted files, empty-source convergence, scoped vault rebuild isolation, and resuming an incomplete clean generation without discarding confirmed chunks.
- [src/vaultspec_rag/tests/integration/test_codebase_integration_search.py](../../../../src/vaultspec_rag/tests/integration/test_codebase_integration_search.py): Code search expectations cover returned code results and snippets/line metadata, language and path filters (including inline path:), reporting when path filters empty results, plus .vaultragignore, .gitignore precedence, and extra exclusions.
- [src/vaultspec_rag/tests/integration/test_content_admission.py](../../../../src/vaultspec_rag/tests/integration/test_content_admission.py): Compares full and changed-path discovery and per-path disposition, then expects consistent admission output from API, service validation, and JSON CLI dry-run views.
- [src/vaultspec_rag/tests/integration/test_content_kind_restart.py](../../../../src/vaultspec_rag/tests/integration/test_content_kind_restart.py): Exercises cancellation after committed document work, then restart/resume against a real store and ledger, checking that committed units remain and the same generation is published.
- [src/vaultspec_rag/tests/integration/test_content_policy_fail_closed.py](../../../../src/vaultspec_rag/tests/integration/test_content_policy_fail_closed.py): Expects invalid/conflicting policy, absent/mismatched/foreign preflight authority, and invalid job admission to fail before model/store/job/cache/durable JSON mutation.
- [src/vaultspec_rag/tests/integration/test_content_route_migration.py](../../../../src/vaultspec_rag/tests/integration/test_content_route_migration.py): Expects real code and document indexers to transfer a file's ownership destination-first when policy routes it between content kinds, clearing the prior collection.
- [src/vaultspec_rag/tests/integration/test_daemon_survives_shell_exit.py](../../../../src/vaultspec_rag/tests/integration/test_daemon_survives_shell_exit.py): Covers stale service-discovery cleanup decisions and Windows daemon spawn escalation when both breakaway and detached spawning fail. The module explicitly excludes a full shell-exit/Job-Object survival reproduction.
- [src/vaultspec_rag/tests/integration/test_dense_backend_integration.py](../../../../src/vaultspec_rag/tests/integration/test_dense_backend_integration.py): Expects a pinned embedding model to remain on the torch path when ONNX is selected, emit a warning, and produce dimensionally valid embeddings.
- [src/vaultspec_rag/tests/integration/test_document_activity_clock.py](../../../../src/vaultspec_rag/tests/integration/test_document_activity_clock.py): Expects a document indexing run against a real server-mode Qdrant to refresh the persisted root last_indexed activity stamp.
- [src/vaultspec_rag/tests/integration/test_document_cli.py](../../../../src/vaultspec_rag/tests/integration/test_document_cli.py): Covers JSON dry-run counts/files for document and combined sources; structured errors for unknown/unsupported source names; empty document/combined search readiness; and document clean/status support-profile projections.
- [src/vaultspec_rag/tests/integration/test_document_execution.py](../../../../src/vaultspec_rag/tests/integration/test_document_execution.py): Covers extractor-owned binary handling and source-size caps, document/code worker boundary, streamed raw-document memory/cancellation behavior, real extractor cancellation and no-progress termination, job-attempt cancellation, admission cancellation checkpoints, document resource/profile limits, independent code/document watcher retries, bounded document slices, and missing publication proof after repeated extraction failures.
- [src/vaultspec_rag/tests/integration/test_document_indexing.py](../../../../src/vaultspec_rag/tests/integration/test_document_indexing.py): Covers raw document full/scoped incremental indexing while code points remain isolated, and extractor-produced document units retaining native metadata without creating code points.
- [src/vaultspec_rag/tests/integration/test_document_lifecycle.py](../../../../src/vaultspec_rag/tests/integration/test_document_lifecycle.py): Expects code indexing and code cleanup to preserve preexisting document points/cache state and avoid launching a document extractor.
