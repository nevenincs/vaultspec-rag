## Limits and reconciliations

Findings describe the inspected snapshot. External dependency internals and operational outcomes were not verified. Test assertions and recorded benchmark results do not establish a current passing run.

- Preprocess cache identity includes extractor/command, options, version, target, mode, byte cap, schema and source-path dependence; the abbreviated docstring is incomplete.
- Non-strict config degradation is narrower than its docstring: unsupported schema and missing/invalid target or extractor_version raise PreprocessPolicyError directly.
- The launcher is not an OS sandbox; external extractor effects remain unverified. Document fragment ID v2 rekeys fragments.
- Empty document stat-gate/placeholder test classes establish no oracle; s1-0163 covers audit refusal only, not successful escalation.
- Preprocess cache docstring abbreviates the key to source hash/command/schema, while implementation fingerprints command or entry-point, options, extractor version, target, mode, byte cap and schema plus source path unless path-independent. Use the implemented cache identity: command/entry-point, options, extractor version, target, mode, byte cap, schema, and source path unless path-independent. The short docstring is incomplete.
- Preprocess config docstring says malformed rules are dropped in non-strict mode, but unsupported config schema, missing/invalid target and extractor_version raise PreprocessPolicyError directly. Preserve direct PreprocessPolicyError for unsupported schema and missing/invalid target or extractor_version. Non-strict malformed-rule degradation is narrower than the docstring; intended wording remains unresolved.
- Named test coverage gap: TestDocumentIndexerGateWiring at test_stat_gate.py:360-362 is empty; full source is covered. The empty TestDocumentIndexerGateWiring class establishes no test oracle. Document indexing implementation is covered by s1-0158 and related tests; full source coverage does not invent missing assertions.
- Coverage qualification, not an established implementation defect: test_daemon_survives_shell_exit.py explicitly excludes full Windows shell-exit/Job-Object survival despite its broad filename. Retain the test's explicit exclusion of full Windows shell-exit/Job-Object survival. Shared process primitives are inspected, but this broader runtime scenario remains unverified.
- Documentation-to-test scope mismatch: test_helpers_qdrant_mirror.py mentions absent-binary fallback, but its assigned test requires a present provisioned host Qdrant binary. The test requires a present provisioned host binary; absent-binary fallback prose is not demonstrated by that scenario. Managed supply/runtime and harness evidence are routed without claiming fallback coverage.
