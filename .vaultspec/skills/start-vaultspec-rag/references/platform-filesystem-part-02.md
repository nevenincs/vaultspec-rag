## Capability summary

- [src/vaultspec_rag/\_win32.py](../../../../src/vaultspec_rag/_win32.py): Platform-neutral importable constants and guarded Windows primitives for child-process Job Objects, process assignment/count/termination, native path lookup, no-follow file/directory opens, and ACL management. It includes separate helpers for creating a protected per-user file and widening shared anchor permissions while preserving existing ACEs.
- [src/vaultspec_rag/\_workspace_layout.py](../../../../src/vaultspec_rag/_workspace_layout.py): Canonical project-root-relative paths for the `.vault` data tree, `.vaultspec` provider directories and manifests, plus the ordered six-directory workspace scaffold.
- [src/vaultspec_rag/api.py](../../../../src/vaultspec_rag/api.py): Public Python facade for vault, code, and routed-document indexing; independent aggregate index outcomes; vault/code search and timed diagnostics; document listing and graph relationships; collection cleaning; code admission scans; status, readiness, installation and service-state reports; and a synthetic quality probe. It resolves roots and delegates through registry leases, with direct preflight paths for code and documents.
- [src/vaultspec_rag/capabilities.py](../../../../src/vaultspec_rag/capabilities.py): Pydantic backend concurrency/storage capability contract and JSON dictionary projection; backend is inferred from configured Qdrant URL.
- [src/vaultspec_rag/concurrency.py](../../../../src/vaultspec_rag/concurrency.py): Lazily initialized process-wide AnyIO capacity limiters for search, index jobs, and encode-bearing index jobs, with bounded queue statistics. Search/index capacities come from configuration; encode admission is fixed to one slot.

## Interfaces and data flow

- The API exports request/options/outcome dataclasses and facade functions via `__all__`. Index entry points accept a workspace path and options; code/document flows preflight content before acquiring a compute lease, then invoke the corresponding runtime indexer. `index_all` wraps vault, code, and document operations separately so one domain's exception is represented as its error outcome without collapsing the others ([src/vaultspec_rag/api.py:232-451](../../../../src/vaultspec_rag/api.py#L232)).
- Search request dataclasses carry the query, root, top-k and domain-specific filters/feedback fields. Search validates filters, resolves the root, checks indexed counts, and uses a search lease; empty indexes return empty results before model-backed search. Timed variants add model-load/project-lease timing fields and indexed counts; the code variant may add publication breadth data ([src/vaultspec_rag/api.py:454-713](../../../../src/vaultspec_rag/api.py#L454)).
- Document/graph reads use registry leases and the graph cache. Vault indexing invalidates that cache after publishing; code indexing does not ([src/vaultspec_rag/api.py:232-338, 716-768](../../../../src/vaultspec_rag/api.py#L232)). Clean uses a maintenance-store lease. Status combines collection counts/storage path with support-profile, lifecycle, and backend capability data ([src/vaultspec_rag/api.py:771-837](../../../../src/vaultspec_rag/api.py#L771)).
- Readiness delegates to a read-only computation without taking a project lease. Service state combines status/error data, registry project snapshots, watcher/controller projections, installation data, root features, Qdrant runtime state, quiesce state and storage schema version ([src/vaultspec_rag/api.py:968-1015, 1191-1331](../../../../src/vaultspec_rag/api.py#L968)).
- Windows helpers use ctypes/Win32 APIs; job operations share `_process_probe.win_kernel32`, and ACL operations bind private Advapi32/Kernel32 instances. Shared anchor ACL grants are merged with existing entries, adding missing requested ACEs before inherited ACEs; no-follow opens disallow delete sharing so the inspected node cannot be replaced while held ( [src/vaultspec_rag/\_win32.py:122-239, 316-643](../../../../src/vaultspec_rag/_win32.py#L122)). The path constants are pathlib Paths relative to the root ( [src/vaultspec_rag/\_workspace_layout.py:37-80](../../../../src/vaultspec_rag/_workspace_layout.py#L37)).
- `BackendCapabilities` selects `qdrant-server` when `qdrant_url` is configured, otherwise `qdrant-local`; its declared contract is concurrent search support, serialized same-project search, parallel cross-project search, and exclusive local-storage process access ([src/vaultspec_rag/capabilities.py:10-55](../../../../src/vaultspec_rag/capabilities.py#L10)).
- Limiter instances are initialized on demand under a threading lock. Search and index token counts are read from config, while encode uses one admission slot; stats expose total, borrowed and waiting token counts, with uninitialized limiters represented as null/zero/zero ([src/vaultspec_rag/concurrency.py:30-121](../../../../src/vaultspec_rag/concurrency.py#L30)).

## Boundaries and dependencies

- Direct local relationships visible in this slice: `api._get_status` calls `backend_capabilities_dict`; API operations use `get_registry` and registry leases; API type annotations describe indexer, search, service, operator-state and watcher-controller types ([src/vaultspec_rag/api.py:17-42, 263-265, 813-837](../../../../src/vaultspec_rag/api.py#L17)).
- [src/vaultspec_rag/\_win32.py](../../../../src/vaultspec_rag/_win32.py) imports `_process_probe.win_kernel32` inside Windows-only operations. API also imports many other package modules lazily. Their implementation and external library behavior were not inspected; no behavior behind them is inferred here.
- [src/vaultspec_rag/\_workspace_layout.py](../../../../src/vaultspec_rag/_workspace_layout.py) centralizes path values, but its consumers are outside the assigned source ranges. Likewise, limiter call sites and any code calling the Win32 helpers are not established by this slice.
- Documentation claims: module/function docstrings describe intended guarantees and tradeoffs, including lease eviction, no-orphan Job Objects, safe readiness polling and limiter partitioning. They are reported as documentation claims, not independently verified runtime facts.
- Test expectations: none observed; tests were outside the assigned ranges and were not read.
